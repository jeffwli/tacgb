# TacGooseBumps project website

Project page: https://jeffwli.github.io/tacgb/

Paper: https://arxiv.org/abs/2609.34006

Static research website, published with GitHub Pages from `main` / repository root.

## Update

Edit `index.html`, `styles.css`, or assets, then push to `main`. GitHub Pages republishes automatically.

Set `youtubeId` in `site-config.js` when the research video is available. Keep asset paths relative so the project works at `/tacgb/`.

Research figures are flattened raster images; manuscript source, original PDFs, and raw research data are not distributed in this repository.
